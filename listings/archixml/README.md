## Bulk-edit Archicad attributes inside the open project. archiXML docks as an Archicad palette and works through the Tapir add-on, so there's nothing to export and nothing to import back.

No Archicad to hand? It still opens and edits an XML export in the browser: that's the optional offline path, and the fallback for the few things the API can't reach.
